# Routes
- Homepage scene is one fixed width-led transform layer of the approved art, one crop per screen shape (landscape, portrait, tall phone; picture media must match the CSS query), (zoomed only to cover the large viewport plus a 32px minimum overscan; drift = its own overscan, capped, driven by one scroll-position-only driver that never reads page height) with its logo painted in; the headline is offset from the logo fraction and surfaces are nine-sliced rasters. A fixed top canopy repeats the same art over content (opaque through the sign, fade below) and, like the compact age rail, follows the same driver via [data-scene-follow] CSS variables — never a second driver or a flat band. Why: art never runs out on long catalogs and studs/corners never stretch. (src/routes/index.tsx + src/puzzle-commons.css)
- Window scroll after render is owned by src/lib/scroll-ownership.ts: the router restores on navigations but never re-applies after hydration, and the menu restores its return-from-game position once (consumed) before paint. Why: a second restore overrides the visitor's own early or deliberate scrolling.
